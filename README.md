### Sobre este desafio

Neste desafio o objetivo é criar um encurtador de URLs completo utilizando os conceitos de Spec-Driven Development

#### O que foi implementado

- API Minimal em .NET 10 para criar, redireccionar e consultar estatísticas de links curtos.
- Persistência SQLite, expiração UTC e contagem atómica de acessos válidos.
- Documentação interactiva Scalar e documento OpenAPI disponíveis em todos os ambientes.

### Documentação da API

Ao arrancar o projecto pelos perfis HTTP ou HTTPS, o browser abre automaticamente a documentação Scalar. Também é possível aceder directamente a `/scalar`; o documento OpenAPI está disponível em `/openapi/v1.json`.

```powershell
dotnet run --project src/Shortener.Api
```

Neste processo eu aprendi:

- A manter especificação, plano, tarefas, testes e implementação alinhados.
- A gerar documentação OpenAPI e apresentá-la com Scalar.
